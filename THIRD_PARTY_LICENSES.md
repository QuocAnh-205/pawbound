# Giấy phép bên thứ ba (THIRD_PARTY_LICENSES)

Tệp này được sinh bởi `scripts/gen_licenses.py`. Gồm nguyên văn giấy phép của thư viện được biên dịch vào bản phát hành
và ghi công asset. Công cụ chỉ dùng khi phát triển/test (doctest, jest…) không được phân phối.

## Tóm tắt

| Thành phần | Phiên bản | Giấy phép | Dùng trong |
|---|---|---|---|
| SDL3 | 3.4.20 | Zlib | client |
| Vulkan Memory Allocator | 3.5.0 | MIT | client |
| GLM | 1.0.3 | MIT (Happy Bunny / MIT) | client, server |
| nlohmann/json | 3.12.0 | MIT | client, server, tool |
| stb (stb_image, stb_easy_font) | d14d46f6b444 | MIT hoặc Public Domain | client |
| cgltf | 1.15 | MIT | client, tool |
| ENet | 1.3.18 | MIT | client, server |
| libsodium | 1.0.22 | ISC | client, server, tool |
| Backend Node.js (NestJS, Prisma, argon2…) | xem `backend/package-lock.json` | MIT / Apache-2.0 | máy chủ backend (không nằm trong gói client) |
| Vulkan loader (`vulkan-1.dll`) | của driver GPU | Apache-2.0 | KHÔNG đóng gói — có sẵn với driver |
